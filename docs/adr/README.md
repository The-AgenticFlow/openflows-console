# Architecture Decision Records (ADR)

This directory records the significant architecture decisions for the OpenFlows Console, following a lightweight ADR format: **Context → Decision → Consequences**.

Each ADR is small, dated, and immutable once accepted (superseding records are added, never edited in place).
